# Asistente Cashea Online — v013

Aplicación estática para preparar archivos Excel de inventario, actualizar productos y cargar descuentos.

## Publicación

1. Descomprime el ZIP en tu equipo.
2. Sube `index.html` y este README a la raíz de tu repositorio de GitHub.
3. Habilita GitHub Pages para publicar la raíz de la rama que contiene esos archivos.
4. Usa el enlace que te indique GitHub Pages al terminar la publicación.

No subas únicamente el ZIP al repositorio: debes subir su contenido descomprimido.
No requiere instalación ni compilación. Necesita conexión a internet para cargar las dependencias originales.

## Versión

Incluye exactamente el HTML v013 adjuntado, renombrado a `index.html`, con sus manuales integrados. No incorpora los cambios de v014.

## Datos y recuperación

Los archivos Excel se procesan en el navegador. El avance se guarda en el almacenamiento del mismo navegador cuando está permitido; no se sincroniza entre usuarios o equipos. La subida de imágenes usa los servicios externos configurados en el asistente.

Para actualizar la web, reemplaza `index.html` por la nueva versión del asistente.
